# תרופה בזמן — אפליקציית תזכורות לתרופות לאנדרואיד

אפליקציה בסגנון Medisafe: עובדת בלי אינטרנט, בלי חשבון ובלי פרסומות. הממשק בעברית.

## מה יש בה
- **מסך "היום"**: רשימת המנות לפי שעה, עם כפתורי "נלקח" ו"דלג", פס התקדמות, וסטטוס (מתוכנן / הגיע הזמן / הוחמץ / נלקח / דולג). אפשר לדפדף בין ימים.
- **התראות בזמן**: התראה עם כפתורים "✓ נלקח", "⏰ עוד 10 דק׳" ו"דלג" ישירות מההתראה. עובדת גם אחרי הפעלה מחדש של הטלפון.
- **ניהול תרופות**: שם, מינון, סוג (כדור, סירופ, טיפות, זריקה, משאף...), צבע, כמה שעות ביום, ימים בשבוע, לפני/עם/אחרי האוכל, הערות, השהיה בלי מחיקה.
- **מעקב מלאי**: המלאי יורד אוטומטית בכל נטילה, ומגיעה התראה כשנשאר מעט.
- **"לקחתי הכול"**: כשכמה תרופות נלקחות באותה שעה, כפתור אחד מסמן את כולן, גם במסך "היום" וגם בהתראה (שמגיעה כהתראה אחת משותפת).
- **"מתי לקחת?"**: בלחיצה על "נלקח" בוחרים: עכשיו, בשעה המתוכננת, או שעה אחרת. אפשר תמיד לשנות את שעת הנטילה ("שינוי שעה" בכרטיס, או לחיצה על השורה בהיסטוריה).
- **דוח PDF** של שנה קלנדרית מלאה (ינואר–דצמבר, לבחירת השנה), או של שבוע, חודש, 3 חודשים ו-12 החודשים האחרונים: סיכום, רשימת התרופות, היענות לכל תרופה ויומן נטילות עם השעות בפועל.
- **דוח היענות**: אחוזים ל-7 ול-30 ימים, גרף לפי יום, אחוזים לכל תרופה והיסטוריה.
- **ייבוא מ-Medisafe**: בהגדרות בוחרים את קובץ ה-CSV שיוצא מ-Medisafe, והתרופות וכל היסטוריית הנטילות (כולל השעות בפועל) נכנסות לאפליקציה.
- **רקעים**: רגיל, שמיים, מנטה, שקיעה, לבנדר, ורוד, חול, לילה (כהה), או תמונה מהגלריה. כל רקע משנה גם את הצבע הראשי של האפליקציה.
- **צליל התזכורת**: בחירת צלצול מתוך הצלצולים של הטלפון, או מצב "רטט בלבד" / "שקט – התראה בלבד".
- **עברית / English**: בחירת שפה בהגדרות. כל הממשק, ההתראות ודוח ה-PDF מתחלפים, כולל כיוון הכתיבה.
- **גיבוי ושחזור** לקובץ JSON.

## איך מתקינים — דרך 1: Android Studio (הכי פשוט)
1. מתקינים את [Android Studio](https://developer.android.com/studio) (חינם).
2. מחלצים את ה-ZIP ובוחרים **File → Open** ואז את התיקייה `MedReminder`.
3. מחכים שהסנכרון (Gradle Sync) יסתיים. בפעם הראשונה זה מוריד רכיבים ולוקח כמה דקות.
4. מחברים את הטלפון בכבל (עם "ניפוי באגים ב-USB" מופעל באפשרויות המפתח) ולוחצים על ▶ **Run**.
   - או: **Build → Build App Bundle(s) / APK(s) → Build APK(s)**, ואז מעבירים את קובץ ה-APK לטלפון ומתקינים.

## דרך 2: לקבל APK מוכן מ-GitHub, בלי להתקין כלום
1. יוצרים מאגר (repository) חדש ב-GitHub ומעלים אליו את כל תוכן התיקייה (כולל התיקייה `.github`).
2. בלשונית **Actions** הבנייה רצה לבד (כ-5 דקות).
3. נכנסים לריצה שהסתיימה ומורידים את **MedReminder-APK**, ובתוכו קובץ ה-APK. מעבירים לטלפון ומתקינים (צריך לאשר "התקנה ממקורות לא ידועים").

## אחרי ההתקנה
פותחים את לשונית **הגדרות** באפליקציה ומוודאים שכל השורות מסומנות ✅:
הרשאת התראות, שעונים מדויקים ו**ללא הגבלת סוללה**. האחרונה חשובה במיוחד בשיאומי, סמסונג, וואווי ו-OnePlus.

## פרטים טכניים
Kotlin, Jetpack Compose (Material 3), minSdk 26 (אנדרואיד 8) ו-targetSdk 35.
הנתונים נשמרים בקובץ JSON פרטי של האפליקציה. התזכורות מתוזמנות עם AlarmManager (שעון מדויק אחד שמכוון תמיד למנה הבאה).
